# 第一轮：移动账单、记账与导航

依据父任务mobile-experience-redesign及审查A01/A04/A06–A09。
前置：最终方案获后续评审确认，且本任务start后才实施。本轮交付后
第二轮才可开始；不是依赖目录顺序。无新的产品决策待澄清。

范围：原生mobile视觉规格、四项短导航及中央记账；摘要紧凑分组和交易
行；搜索/筛选独立面板；单金额区、分类快捷网格、日期可见、更多信息、
单计算器与底部可达保存；紧凑详情和所有可见模态的系统返回优先级。
完整技术/交互设计以父design第一轮及视觉规格为准。

验收：
- [x] 两locale的320/375/457px无页面横溢、长金额与眼睛不重叠；隐藏
  汇总DOM无真实金额，临时揭示各自独立，导航标签不折成多排。
- [x] 457×999默认账单首屏能看见月上下文、摘要及至少两条合成记录；
  收支/分类/日期/金额/正则筛选保留，应用后结果数/清空动作明确。
- [x] 默认录入金额/分类/日期/计算器/保存可达；更多信息和文本IME下
  保存不被遮挡，金额仅一个展示区，首次不弹OS数字IME。
- [x] 分类打开不自动弹文字IME，搜索可手动聚焦；选择、关分类、关
  录入、重开草稿正确，真实Android BACK不误退出详情/图片。
- [x] 编辑、附件stage、多split只读、观测revision、写成功刷新失败
  不重放、隐私及离线保持；Web/Electron既有入口与布局无回归。
- [x] 类型检查、unit、focused/full Web及隔离APK实机有实际证据，
  视觉目检通过后共享规格写入稳定spec供后续复用。

不改数据层、路由路径、同步/统计/设置正文。详情返回修复可能作用于
其他host同一模态，但原生bridge安全边界不变。起点21条dirty变更
保留，不把它们误当可回滚内容。
