## Requirements

- 手机设置子页提供返回设置、当前页标题和按需展开的区域切换，不先展示完整导航目录。
- 导航控件达到项目 44px 目标；图表有大目标日期选择和文字明细。
- 常规建账使用账本语言和币种默认精度；高级字段仍可达。登录前后按任务阶段展示，不暗示登录即上传。

## Acceptance criteria

- [x] C01：375×800 中英文偏好页语言/隐私主控件在首屏可用；320×568 英文至少当前标题和首个主控件可见。
- [x] C02：返回/区域切换、原 URL、当前项语义、键盘、低动效保持可用，桌面不退化。
- [x] C03：底栏点击区域至少 44×44；手机每日统计选择通过大控件完成，任意日期可达，不依赖重叠 hitbox；保留文字明细、金额和未来日语义。
- [x] C04：默认建账填写名称即可提交；JPY 为 0 位、常用币种为 2 位，高级精度可见可改，预算明确可选。
- [x] C05：账号登录/连接/解锁各阶段有明确下一步和返回；技术帮助按需展开；密码默认隐藏且可显隐，不改变会话和秘密持久化边界。

## 约束与依赖

保留离线写入、备份/同步、最初观察的 revision/heads、草稿、防重提交、中英文、现有 URL、summary-only 隐私及键盘/低动效。既有未提交设置整理属于用户基线，不可覆盖。

依赖 A/B 的入口、页头和状态边界；串行修改 shell/styles，不能覆盖前两批。

## Out of scope

不更换设计系统，不新增远程字体，不重做 Android/Electron 外壳，不改变统计计算口径或账号同步权限。
