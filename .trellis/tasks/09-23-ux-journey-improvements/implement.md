## 集成检查

每批先运行其 focused Playwright，然后运行：

```sh
./hako npm run typecheck
./hako npm test
./hako npm run web:build
./hako env LUNA_TEST_PRODUCTION=1 npm run test:web -- --workers=4
git diff --check
```

涉及 host/API 时追加 contracts、server、server-sync；涉及原生边界时追加对应构建/smoke。开发环境的生产用例 skip 不等于验收。
