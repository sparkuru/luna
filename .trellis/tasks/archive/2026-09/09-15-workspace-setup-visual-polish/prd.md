# 优化工作区初始化界面视觉

## Goal

改善工作区初始化页的首屏布局、留白、表单卡片与品牌视觉层级

## Confirmed Facts

- 截图展示的是没有本地工作区时的 `Setup` 初始化页，不是远端账号登录页。
- 当前页由 `src/renderer/features/setup.tsx` 的品牌说明区和工作区表单卡片组成。
- `src/renderer/styles.css:1417-1460` 使用两列网格、`align-items: center` 和
  `min-height: calc(100vh - 8rem)`；表单卡片内容较高，因此品牌说明会被垂直
  居中到卡片中段，造成首屏上半部分留白明显、两侧视觉重心不一致。
- 当前初始化流程包含工作区名称、币种、小数位数、每月支出上限和本地保存说明；本次不涉及其数据逻辑。

## Requirements

- 首屏改为明显的居中欢迎页构图：品牌说明置于表单卡片上方并居中，不再与表单
  卡片并排，避免卡片高度造成两侧视觉重心失衡。
- 页面内容应在可用首屏区域内形成稳定、紧凑的垂直节奏，减少截图中大面积无意义留白。
- 表单卡片应收敛为适合阅读的单列宽度，标题、说明、字段和主按钮保持清晰层级。
- 保留现有初始化字段、校验、错误提示、语言切换、键盘操作和离线本地保存语义。
- 在窄屏下自然改为单列，表单仍可滚动且不产生横向溢出。

## Acceptance Criteria

- [x] 桌面首屏呈现居中的垂直欢迎页：品牌说明位于表单卡片上方，二者共享同一视觉轴线。
- [x] 表单卡片宽度、内边距和字段间距协调，主要操作按钮仍然突出但不过度占据页面。
- [x] 375px 及以上窄屏保持单列、可读、可操作，无横向滚动。
- [x] 创建工作区、错误聚焦、语言切换和现有字段行为不变。
- [x] 类型检查、Web 构建、相关 Playwright 回归和 diff 检查通过。

## Key Decisions

- 采用“品牌说明在上、表单卡片在下”的单列居中构图，而不是继续调整双栏比例。
- 通过现有 `.setup-shell`、`.setup-copy` 和 `.setup-card` 的语义结构完成视觉重排，
  不新增路由或数据状态。
- 保持月白/靛蓝品牌基调和现有表单控件，只调整宽度、对齐、留白、垂直节奏与响应式规则。

## Risks / Deferred Items

- 这是一项主观视觉改动；Playwright 可验证布局、可见性和操作语义，但最终视觉偏好仍需截图人工确认。
- 不做真实账号登录页；当前页面继续承担首次创建本地工作区的职责。

## Out of Scope

- 不新增登录、注册、远端账号或工作区选择流程。
- 不改变工作区创建 API、默认分类、预算、小数位数或本地存储行为。
- 不更换 Luna 的月白/靛蓝品牌基调、图标系统或整体应用导航。
