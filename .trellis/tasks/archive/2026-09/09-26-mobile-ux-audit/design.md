# 审查方法

审查对象是已安装的真实手机界面；代码清单用于避免漏页，不能代替
实际操作。每页从可见入口进入，观察首屏，再展开/滚动到主要操作和
底部，返回上一层。需要输入的地方观察系统IME和控件可达性。

以内容优先、清晰层级、适量密度、Android触控目标、局部错误提示、
一致导航和可发现操作评估；保留现有月白靛蓝、系统字体和Lucide作为
当前产品约束。UUPM原始输出只作审查参考，不照搬营销hero、远程字体、
React Native或新的图标库。改进方案是候选建议，不是已批准设计。

截图由Android screencap捕获；布局/控件元数据由CDP只读收集。合成
账本验证前必须断言名称；保存和删除等操作不用于这轮无损检查。
源码推断及需要登录/连接/真实冲突的未测状态，明确单列。
