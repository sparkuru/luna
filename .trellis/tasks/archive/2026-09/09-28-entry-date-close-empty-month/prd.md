# 记账日期、关闭图标与空月份提示

## Goal

修正用户在三张 2026-09-28 截图中指出的记账界面问题，让日期易读、弹窗关闭动作清晰，切换到没有交易的月份时显示符合所选月份的空状态。

## Confirmed facts

- 记账日期目前是原生 `input[type=date]`，持久化值为 `YYYY-MM-DD`，可见分段顺序受浏览器/WebView locale 影响；用户截图显示为 `MM/DD/YYYY`。
- 记账弹窗 `#close-transaction` 目前显示文字“关闭”；现有 `requestClose` 处理未保存草稿及返回焦点。
- 账单列表以所选月份过滤交易；当前月份交易数为零时，不论账本在其他月份是否有交易，均显示“从第一笔开始”。
- 当前工作树有其他移动端任务的未提交改动；本任务只修改上述呈现，不清理或覆盖那些改动。

## Requirements

1. 原生移动端及窄屏 Web（宽度小于 768px）记账弹窗中的日期可见格式固定为 `YYYY/MM/DD`，不随系统/WebView locale 变为 `MM/DD/YYYY`；日期实际值、原生选择器、键盘和保存语义保持现有契约。桌面 Web/Electron 的日期行为不变。
2. 记账弹窗顶部关闭按钮显示 Lucide `X` 图标，保留本地化可访问名称及原有关闭/草稿保护行为；原生移动和窄屏 Web 的触控框统一为 48×48 CSS px。
3. 所选月份没有交易且未启用筛选时，无论账本是否已有其他月份交易、也无论是否首次使用，都只显示包含所选月份的空状态消息，例如“2026年7月暂无记录”。该空状态不显示“从第一笔开始”、“记一笔”引导或额外记账按钮；页面原有的“添加交易”入口保留。已有交易但筛选无匹配时仍显示筛选空态。
4. 窄屏 Web 统计页在 320/375/457px 宽度下，标题、周期控件、筛选控件和卡片与屏幕边缘至少保持 24 CSS px 的可见间距，且无横向溢出；桌面 Web/Electron 的布局不变。

## Out of scope

- 不改变交易日期存储格式、同步协议、统计或预算周期格式。
- 不重做其他弹窗按钮，也不改变未填写交易的保存校验。
- 不修改 VPS 或已安装的正式 Android 包；真机验证使用隔离构建。

## Acceptance criteria

- [x] 原生 Android 与窄屏 Web 记账日期可见文字为 `2026/09/28` 这种年/月/日顺序；原生输入仍持有 `2026-09-28`，可通过原生选择器改日并正确保存。桌面 Web 日期行为无回归。
- [x] `#close-transaction` 只显示 X 图标，屏幕阅读器仍读出本地化“关闭”，点击和 Escape 均沿用现有草稿保护；原生移动和窄屏 Web 点击区域为 48×48px。
- [x] 首次打开空账本、切换到其他空月份、账本已有交易但所选月份为空时，均显示与所选月份一致的单条空状态消息，不显示首次记账或“记一笔”提示/按钮；同月筛选无匹配时显示筛选空态，页面“添加交易”入口仍可用。
- [x] 窄屏 Web 统计页标题、周期/筛选控件和卡片距左右屏幕边缘至少 24px；320/375/457px 下无横向溢出，桌面 Web/Electron 布局无回归。
- [x] 类型检查、相关 Playwright 回归和构建通过；对窄屏 Web 与隔离 Android 截图确认视觉结果。
