# 简化筛选与预算月份操作

## Goal

让用户快速搜索账单，并直接在预算页选择要设置的月份，同时保留所有筛选和草稿保护。

## 状态和证据

2026-09-23 用户已批准本规划；A–D 可实施，E 仅设计研究。实际执行状态以 task.json 为准。问题编号：F09。父任务 [总体 PRD](../09-23-ux-journey-improvements/prd.md) 与 [原始审计](../09-23-ux-journey-improvements/research/体验评估与修改计划.md) 为来源，所有截图/JSON 在父任务 research 下。

## 已确认问题

- F09/P3：手机展开筛选后先遍历类型和分类再到文本搜索，日期金额继续拉长表单；存在清除与空态，属于效率问题而非功能断路。证据 probe-no-results.png，锚点 features/ledger.tsx:1284。
- 预算编辑页只有月份标签，缺少本页月份选择；用户需先在别处切月份。锚点 src/renderer/features/budget.tsx:54、:89。

## Requirements

- 常用搜索、类型和分类优先；日期/金额作为高级筛选，当前条件和清除操作始终可发现。
- 预算页直接选择月份，未保存草稿切月时确认且可取消。
- 过滤组合、月份约束、异步查询状态和预算并发保护完全保持。

## Acceptance criteria

- [x] D01：手机文本搜索无需展开高级日期/金额；已有高级条件即使折叠仍有可移除 chip，清除一次重置全部条件。
- [x] D02：invalid/working/failed 不伪装为空结果，不清空上次正确结果；类型与分类 AND/OR、绝对金额和当前月边界不变。
- [x] D03：预算页直接切换月份并显示对应预算，保存仅影响所选月；未保存切换可取消并保留原值，确认后进入新月。
- [x] D04：其他标签更新预算后旧草稿提交仍被拒绝，用户输入及原始 heads 保留。

## 约束与依赖

保留离线写入、备份/同步、最初观察的 revision/heads、草稿、防重提交、中英文、现有 URL、summary-only 隐私及键盘/低动效。既有未提交设置整理属于用户基线，不可覆盖。

建议在 C 后实施，复用设置/预算页面标题结构；保持 A/B/C 修改。

## Out of scope

不新增跨月查询，不改变预算数值模型，不删除高级筛选或原生日期输入能力。

交互方案见 design.md，用户已批准按此范围实施。实际设备与辅助技术按父任务边界另行验收。
