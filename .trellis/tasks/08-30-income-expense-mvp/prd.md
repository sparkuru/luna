## Goal

在已确认的产品基线之上，交付一个可以实际使用的离线桌面记录器纵向切片，并在其上增加人民币、中英双语、金额隐私配置和可真实跨设备恢复的配置同步。账本远端同步仍按独立证据推进；本轮配置同步不得被描述成账本数据已经同步。

## Background and confirmed facts

- 仓库根目录 `prd.md`（v0.2，2026-08-30）是已确认的产品基线。
- 产品是面向个人、伴侣和小型家庭的跨平台、离线优先收入/支出记录器，可选月度开支上限；它不维护账户实际余额。
- 用户可见交易类型只有收入和支出；金额使用记录币种最小单位的有符号整数，分类拆分必须精确求和。
- 本地保存先于同步；统计由本地最新有效版本重算；关键财务字段的并发修改必须显式冲突处理；删除使用墓碑并延迟清理。
- 首个正式客户端是 Electron 桌面端，复用平台无关的 Web UI 和领域逻辑，并使用原生 SQLite；同时提供用于设计与自动化验收的浏览器 Web 预览，浏览器 MVP 使用 origin-local storage，不承诺 PWA、浏览器 SQLite WASM/OPFS 或与桌面账本自动互通。
- MVP 的同步目标是用户提供的 S3/OSS 兼容对象存储。对象存储只保存客户端加密后的数据；不部署专用 Relay，不提供托管同步账号或服务端明文账务查询。
- 产品基线仍将具体密码套件与参数、对象布局、操作编码、因果协议、供应商兼容矩阵、密钥轮换和浏览器存储限制列为技术研究事项。
- 当前仓库没有应用源码、包清单、CI、测试框架、浏览器配置或开发命令包装器，技术栈尚未选定。
- 归档的 PRD 决策评审已经关闭原产品层八项待决策；本任务不重新打开这些已确认的产品边界。

## Requirements

- 规划必须以根目录 `prd.md` 为产品行为权威，并把首个交付限定为可独立验证的工作范围。
- 规划必须明确本次交付的目标、范围边界、可观察验收标准，以及仍需研究但不改变 MVP 行为的技术未知项。
- 任何产品代码实现都必须在规划完成、用户明确批准并执行 `task.py start` 后开始；这些前置条件现已满足。
- 工作区继续使用 ISO 4217 代码保存币种；“RMB”在领域与持久化中规范化为 `CNY`，界面按当前语言显示“人民币 / Chinese Yuan”和 `¥`。
- i18n 首批覆盖 `zh-CN` 与 `en`，所有新增及既有用户可见文案都必须通过消息键获取；金额、月份和日期使用当前 locale 的 `Intl` 格式化。
- 金额隐藏偏好必须写入版本化本地配置文件。默认隐藏时，仅顶部收入、支出、结余和剩余预算汇总金额遮罩；预算编辑值、预算使用/上限文本、分类统计和交易列表金额保持可见。汇总隐藏时顶部卡片行收缩；DOM、无障碍名称和状态播报不得泄露被隐藏的汇总数值；本次临时展示状态不持久化。
- 配置同步必须使用用户提供的 S3/OSS 兼容对象存储，上传客户端加密后的版本化配置对象。新设备完成一次远端连接与同步口令引导后，可恢复所有被允许同步的设置。
- “同步所有设置”是配置同步总开关：开启时同步全部 portable settings，关闭时不读写远端配置。对象存储密钥、同步口令/主密码、本机路径、设备 ID、窗口状态和临时金额展示状态始终仅保存在本机，永远不上传。
- 同步默认采用确定性的整份配置合并：每个字段携带更新时间，同字段并发更新先比较 `updatedAt`，完全相同时以规范化字段值裁决；设备 ID 保持本机专属，不作为远端 tie-breaker 上传。未知字段保留或安全忽略，schema 不兼容必须明确报错而不是覆盖本地配置。
- 本地数据位置是设备级设置，不参与远端配置同步；选择其他目录不能改变远端 payload 的字段边界，也不能把本机路径暴露给 renderer 或对象存储。

## First delivery decision

用户已批准本任务的第一段交付采用根 PRD 的阶段 0“边界与技术验证”。本阶段的目标是验证基础领域边界和高风险技术假设，形成可以支撑后续正式实现的技术结论；它不是完整可用的记账产品发布。

### In Scope

- 建立最小的、平台无关的收入/支出领域模型验证，覆盖单币种、整数金额、分类拆分、月度预算、最新有效版本和基础修订语义。
- 验证 Electron 桌面端使用原生 SQLite 保存数据、执行最小迁移，并在离线重启后恢复交易及其必要状态。
- 对浏览器 SQLite WASM/OPFS 做隔离的技术 Spike，记录持久化、锁、容量、恢复和多标签限制；不把 Spike 自动升级为 PWA 承诺。
- 验证端侧加密/解密边界、主密码改包裹 root key、无密码恢复失败路径和必要的数据丢失提示；具体密码套件和参数仍需安全研究，不在本阶段未经依据定案。
- 用两个客户端验证新增、编辑、删除、重复上传和冲突展示的最小变更模型；财务关键字段不得以盲目最后写入静默覆盖。
- 验证至少一个经过测试的 S3 兼容对象存储适配器的最小上传、下载、幂等和失败重试路径；供应商支持范围以实际测试结果为准。

### Out of Scope for Phase 0

- 完整的生产级记账 UI、附件体验、报表体验、冲突收件箱和所有 MVP 功能的交付。
- 完整的多设备同步服务、供应商广泛兼容矩阵、移动端、完整 PWA 或后台同步保证。
- 在没有独立安全评审和测试向量前宣称密码方案已审计、实现已达到生产安全等级，或实现密钥撤销/轮换承诺。
- 产品命名、账户余额、转账、退款交易类型、专用 Relay、成员角色和多币种。

## First usable checkpoint

阶段 0 的技术边界仍然有效；在其基础上，最新用户授权把本轮的第一个可用检查点明确为本地离线桌面纵向切片。该检查点完成后，远端同步、生产级端侧加密和浏览器 OPFS 仍保持延期，不以临时实现宣称已完成。

### In Scope for the checkpoint

- Electron 桌面应用可以启动并在本机工作区中运行，不依赖网络。
- 首次启动可以建立工作区名称、币种和月度开支上限；界面明确标注远端加密同步尚未启用。
- 用户可以新增、编辑和删除收入/支出记录，填写金额、日期、分类、商户、支付方式和备注。
- 应用可以在关闭并重新打开后恢复本地记录，显示月度收入、支出、结余和预算进度。
- 所有本地写入通过共享领域校验和窄化 IPC 到 SQLite；删除不会让记录继续进入统计。

### Out of Scope for the checkpoint

- 远端对象存储同步、双端冲突收件箱、附件和完整加密工作区。
- 浏览器 PWA、移动端、账户余额、转账、退款、成员角色和多币种。

## Configuration and internationalization extension

### In Scope

- 新建工作区时提供 `CNY — 人民币`，并用 locale-aware currency formatter 正确显示人民币。
- 提供中文（简体）和英文界面切换，语言选择持久化并可参与配置同步。
- 提供“默认隐藏金额”持久化开关和清晰的临时显示/隐藏控制；首次安装默认隐藏。
- 使用当前活动本机目录下的 `settings.json` 保存经过严格解码的版本化非秘密设置，并使用同目录临时文件 + rename 原子替换；Linux 默认目录为 `~/.config/luna`，不再追加 `luna-ledger/`。
- 提供 S3/OSS 兼容远端连接设置、连接验证、上传、下载和手动同步；配置密文使用版本化 envelope，条件写入避免无提示覆盖。
- 提供“同步所有设置”开关。开启后同步全部 portable settings；关闭后不执行远端配置读写、不覆盖本机展示偏好，也不删除已有远端对象。
- 至少用两个独立本地客户端配置目录及一个受控 S3-compatible 测试端验证上传、下载、新设备恢复、重复同步和冲突裁决。
- 应用统一显示为 `Luna`，Linux 默认本地配置根目录为 `~/.config/luna`；启动时若默认目录在进程启动前已存在则直接进入（即使为空），只有启动前默认目录不存在时才显示可访问的原生选择流程，用户可以创建默认目录、选择其他本地目录或取消退出。
- 选择其他目录后将位置选择以本机私有指针记住；后续启动直接使用该目录。配置文件、SQLite 数据库和本机秘密均位于当前选择的目录，远端同步不包含该目录路径。
- 提供 `npm run web` 浏览器入口，复用同一套 renderer、共享领域类型和 API 契约；浏览器数据仅保存在当前 origin 的 `localStorage`，配置同步入口明确标记为桌面端能力，不读取 Node/Electron/SQLite 或任何秘密。
- Web 入口必须能在无预置数据的干净浏览器上下文中创建工作区、录入交易、显示 CNY 和预算，并在 reload 后恢复浏览器本地数据；它是设计与验收用 Web MVP，不扩大为 PWA、跨端数据互通或浏览器端远程同步承诺。

### Out of Scope

- 本轮不把交易、预算、附件或 SQLite 数据上传；账本同步、财务冲突收件箱与完整工作区端侧加密仍是后续里程碑。
- 不承诺未经 conformance 测试的所有 OSS/S3 供应商；界面必须把支持范围描述为“经过测试的 S3-compatible endpoint”。
- 不同步任何凭据、口令、主密码、本机路径、窗口布局或会话级金额展示状态。
- 不在本轮提供组织账户、官方托管同步服务、后台常驻同步或移动端客户端。
